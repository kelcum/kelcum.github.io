What you get

Quiet by default. Sharp where it counts.

Everything in Equicord, plus the parts that make this fork its own.

Its own boot splash

Replaces Discord’s connecting screen with an animated chrome crest and Deadbolt-branded quotes, instead of just re-texting the default one.

Animated profile badges

A constantly shining chrome Creator badge and a violet Contributor badge, each with a proper hover card. Click Contributor to see that person’s plugins.

/addplugin

Add a plugin without leaving Discord. Attach the file and Deadbolt saves it, rebuilds, and offers to reload. No editor, no terminal.

needs a from-source install

macOS done properly

Injects through Discord’s external discord_desktop_core module, so Discord.app is never modified and its Apple signature stays valid. No “damaged app” warnings.

A default look

Fresh installs start on a black, grayscale QuickCSS theme that tidies away Nitro and gift buttons, stickers, Discover and more. It never overwrites a QuickCSS you already have.

Small plugins that earn their spot

ConfirmMassMention asks before an @everyone goes out. DoubleSendGuard catches an accidental double-send. Plus SilentFolder, BetterMicQuality, VSCodeActivity and more.

Heals itself on Windows

Discord’s updater loves to reset mods. One script puts everything back, and an optional scheduled task keeps Deadbolt synced with upstream and tells you if it gets stuck.

The whole Equicord library

300+ plugins from Equicord and Vencord come along for the ride, so nothing you rely on goes missing.

Install

Pick your platform.

Windows has a one-click installer. macOS and Linux get a one-line script.

One-click installer

Downloads the latest Deadbolt build and walks you through picking your Discord install: Stable, PTB or Canary.

  1. Download and run DeadboltSetup.exe.
  2. Pick your Discord install when it asks.
  3. Fully quit Discord (check the system tray), then reopen it.
Download DeadboltSetup.exe about 55 MB · latest release

The installer isn’t code-signed, so Windows SmartScreen may warn you. Choose More info, then Run anyway.

Or build from source

Needs Git and Node.js 22+. Building from source also unlocks /addplugin and the auto-update script.

git clone https://github.com/kelcum/Deadbolt
cd Deadbolt
npm i -g pnpm
pnpm install --frozen-lockfile
pnpm build
pnpm inject

After a Discord update

One command

Builds Deadbolt and injects it through Discord’s external discord_desktop_core module. /Applications/Discord.app is never touched, so its Apple code signature stays valid: no “Discord is damaged”, no re-signing, no Gatekeeper fights.

$ curl -fsSL https://xan.gripe/deadbolt/install-macos.sh | bash

Needs Git, Node.js 22+ and pnpm. The script checks and tells you what’s missing.

Full macOS guideRead the script first

One command, any distro

The script checks that Git, Node.js 22+ and pnpm are installed and, if one is missing, prints the right command for your distro. It never runs a package manager for you.

$ curl -fsSL https://xan.gripe/deadbolt/install-linux.sh | bash

Per-distro setup, update and uninstallRead the script first

Run these as your normal user, never from an admin or root terminal. It will mess up your Discord and you’ll most likely have to reinstall.
